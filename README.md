One word for the boss: **nanomanager**. A micromanager manages every little thing you do; a nanomanager manages at an even smaller scale — every keystroke, every minute, every breath between the keystrokes. The program writes exactly that one word to `/output/entry.txt`, nothing else.

## Run it

```sh
python3 main.py
```
